# The Word You'd Delete from the Dictionary

**The word: `irregardless`.**

"irregardless" is a word that only exists because people keep using it wrong — a mash-up of "irrespective" and "regardless" that, taken literally, means the opposite of what the speaker intends. Dictionaries list it only with a sigh, marked "nonstandard". Deleting it would instantly make every sentence that used it more correct, and nobody who loves the language would miss it for a second — except the people who say it, who would finally have to pick a real word. The joke lands the moment you read it: a word so wrong that deleting it is the only edit it ever needed.

Why not "moist"? "Moist" is the cliché answer — everyone has heard it a hundred times, so it lands as a reference to a meme rather than a fresh joke. "Irregardless" wins on freshness while still landing instantly: it's a real linguistic crime, not just an unpleasant sound, a word that contradicts itself, so deleting it is both funny and logically justified. The reader gets it with no setup — but hasn't seen it as the answer to this question before.

## How to run

```sh
node main.ts
```

This writes exactly one word, `irregardless`, plus a trailing newline, to `/output/entry.txt`.
